# Données du monde

`data/world.json` contient des données générées automatiquement pour amorcer la conception :
- 50 pays fictifs ;
- 14 à 17 régions par pays ;
- une capitale nationale et une capitale régionale par région ;
- villes en nombre variable selon le type de région ;
- nombre indicatif de villages et tags d'infrastructures.

Ces noms sont des placeholders de génération et doivent être relus, améliorés et accompagnés d'histoires, drapeaux et cartes originales. Les données ne créent pas automatiquement des environnements 3D dans Roblox Studio.
