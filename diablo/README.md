# Diablo — Orchestrateur de développement SFO

Diablo coordonne progressivement les tâches de développement de
SHADOW FRONT: GLOBAL OPERATIONS (SFO).

## Principes
- Le dépôt SFO reste la source officielle du code.
- Les tâches sont suivies et journalisées.
- Les modifications importantes nécessitent une validation.
- Aucun déploiement automatique sans configuration et tests préalables.

## État initial
Structure de travail uniquement : aucune tâche autonome n'est encore exécutée.
